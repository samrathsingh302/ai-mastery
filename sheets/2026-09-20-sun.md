### 5. `ex09_etcetera.py` — the finishing moves

- **File:** `C:\Users\samra\repos\ai-mastery\modules\03-cs50p-accelerated\exercises\ex09_etcetera.py`
- **What:** `top_n(scores, n)` returns the top `n` `(name, score)` pairs, highest score first, ties
  broken **alphabetically**; `evens_squared(nums)` is one comprehension returning the square of each
  even number, in order.
- **A different worked example of the sort trick** — longest words first, alphabetical on ties:

  ```python
  words = ["pear", "fig", "plum", "apple"]
  sorted(words, key=lambda w: (-len(w), w))     # -> ['apple', 'pear', 'plum', 'fig']
  [w.upper() for w in words if len(w) > 3]      # -> ['PEAR', 'PLUM', 'APPLE']
  ```

  The whole idea: **a key returning a tuple sorts by each slot in turn**, and negating a number
  reverses just that slot — which is how you sort descending on one field and ascending on another
  in a single pass. The comprehension reads `[what I want for each x in xs if x qualifies]`.

### 8. Propositional logic — truth tables, entailment, satisfiability

- **Why now:** COMP5450M (KRR) assumes it and UNI-PREP.md §1 puts it in this week. It is three
  definitions and one method; everything later in the module stands on them.
- **The three definitions, in one place:**
  - A **truth table** enumerates every assignment of true/false to the variables and gives the
    formula's value for each. `n` variables → `2ⁿ` rows, always.
  - **Satisfiable** = *at least one* row makes it true. **Valid** (a tautology) = *every* row does.
    **Unsatisfiable** = none. `P ∨ ¬P` is valid; `P ∧ ¬P` is unsatisfiable; `P ∧ Q` is merely
    satisfiable.
  - **Entailment**, written `KB ⊨ α`: *every* row that makes the knowledge base true also makes α
    true. The test that actually gets used: **`KB ⊨ α` exactly when `KB ∧ ¬α` is unsatisfiable** —
    which is why a SAT solver is an entailment checker in disguise, and why resolution (W4') works.
  - Watch the one that bites everyone: `P → Q` is **true** whenever `P` is false. "If it rains I take
    an umbrella" is not broken by a dry day.
- **Do it by hand first:** write the full truth table for `(P → Q) ∧ (Q → R)` and check whether it
  entails `P → R`. Four variables' worth of rows is not a hardship; do it on paper.
- **Then make it checkable** — write `C:\Users\samra\repos\ai-mastery\prolog\truth_tables.py` (creates):
  a function taking a list of variable names and a predicate over an assignment dict,
  printing the table; then assert your entailment answer. `itertools.product([False, True],
  repeat=n)` gives you every row in one line — the same comprehension muscle as ex09.
- **Check (from `C:\Users\samra\repos\ai-mastery`):**

  ```
  python prolog\truth_tables.py
  ```
- **Done when:** it runs silently (your asserts hold) and your hand-written table agrees with it. If
  they disagree, the paper is usually right and the code has the implication backwards.
