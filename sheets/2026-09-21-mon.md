### 2. `ex05_subprocess.py` — launching other programs → **Gate 1**

- **File:** `C:\Users\samra\repos\ai-mastery\modules\04-automate-boring-stuff\exercises\ex05_subprocess.py`
- **What:** `python_version()` runs *this* Python (`sys.executable`) with `--version` and returns just
  the number; `git_head_short(repo_path)` returns `git rev-parse --short HEAD` run in that folder,
  stripped, or `None` when the command fails.
- **The law of this rung: arguments go in a LIST, never a shell string.**

  ```python
  import subprocess, sys
  r = subprocess.run([sys.executable, "-c", "print(2+2)"],
                     capture_output=True, text=True)
  r.returncode, r.stdout.strip(), r.stderr.strip()     # -> (0, '4', '')
  ```

  A list means the OS gets your arguments exactly as written — no quoting bugs, no injection when a
  path has a space in it. `text=True` gives you strings instead of bytes. And check
  `returncode`: a program that failed still *returns*, it does not raise.
- **The deliberate gotcha in `python_version()`:** older Pythons print the version to **stderr**,
  newer ones to **stdout**. Handle both; that is the exercise.
