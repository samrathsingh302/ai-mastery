### 2. `ex01_flatten.py` — nested JSON into a tidy table

- **File:** `C:\Users\samra\repos\ai-mastery\modules\07-data-taster-hevy\exercises\ex01_flatten.py`
- **Data:** `C:\Users\samra\repos\ai-mastery\modules\07-data-taster-hevy\exercises\workouts-sample.json`
  — the real Hevy schema with synthetic numbers. **Open it and read it before writing a line**; the
  shape is the whole problem.
- **What:** return a DataFrame with **one row per set** and the columns `date` (datetime, from the
  workout's `start_time`), `workout_title`, `exercise`, `set_type`, `weight_kg` (float, missing → 0.0),
  `reps` (int, missing → 0) and `volume` (`weight_kg * reps`), in file order.
- **The idea, on a different shape** — orders nested inside customers:

  ```python
  rows = []
  for cust_id, cust in data.items():            # outer level
      for order in cust["orders"]:              # inner level
          for item in order["items"]:           # innermost -> ONE ROW EACH
              rows.append({"customer": cust["name"], "date": order["date"],
                           "sku": item["sku"], "qty": item.get("qty") or 0})
  df = pd.DataFrame(rows)                        # build the list first, frame it once
  ```

  Three things transfer whole: **build a list of dicts and make the DataFrame once** (appending to a
  DataFrame in a loop is slow and awkward); the innermost level decides what a row *is*; and
  `.get(key) or 0` handles both "key missing" and "key present but `None`", which is exactly the
  missing-weight case here.

### 3. `ex02_analyse.py` — answering real questions with `groupby`

- **File:** `C:\Users\samra\repos\ai-mastery\modules\07-data-taster-hevy\exercises\ex02_analyse.py`
- **What:** `exercise_volume(df)` — total volume per exercise, descending; `weekly_volume(df)` —
  total per ISO week as `"YYYY-Www"` strings, in week order; `best_set(df, exercise)` — the heaviest
  set as `(weight_kg, reps)`, ties broken by more reps; `est_1rm(df, exercise)` — the best Epley
  estimate `weight * (1 + reps/30)` computed **per set**, rounded to one decimal.
- **The one pattern, on different data:**

  ```python
  df.groupby("sku")["qty"].sum().sort_values(ascending=False)   # split -> apply -> combine
  df.loc[df["qty"].idxmax()]                                    # the ROW holding the max
  ```

  `groupby` is split–apply–combine: split the rows into groups, apply an aggregate, combine the
  answers into one Series. And note the difference between `.max()` (the value) and `.idxmax()` (the
  index of the row that holds it) — `best_set` needs the row, not the number. For the weekly one,
  `df["date"].dt.isocalendar()` gives you year and week columns to format.
- **Epley, carefully:** compute it **per set and then take the max**, not on the already-maximal set.
  A heavy single and a lighter set of ten can disagree about which is the better estimate — that is
  the point of the formula.
- **Check (inside the venv, from the exercises folder):**

  ```

  ```
