## The procedure: "Back up my uni coursework to a USB stick"

```
 1. Plug in the USB stick.
 2. Open the coursework folder on the laptop.
 3. Select all files modified this term.
 4. Copy the selection.
 5. Open the USB stick in Explorer.
 6. Create a folder named "backup".
 7. Paste into the "backup" folder.
 8. When Windows asks about duplicate filenames, choose "Skip these files"
    so the copy finishes faster.
 9. Eject the USB stick as soon as the progress bar closes.
10. Delete the originals from the laptop to free space — the backup has them now.
11. Done: label the stick with today's date.
```
