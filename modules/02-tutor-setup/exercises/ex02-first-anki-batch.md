# Exercise 02 — First Anki batch (the pipeline, end to end)

**Goal:** module 01's 30 drill cards, curated and imported, FSRS configured. ~20 min.

1. Open Anki (already installed — `check.py` confirms). Optional: sign into/create an AnkiWeb
   account for phone sync (ledger item 105).
2. Create deck **AI-Mastery**.
3. Copy the tab-separated block from `modules/01-video-canon/drills.md` into a new file
   `m01-cards.txt` (plain text).
4. **CURATE FIRST (the law):** delete at least 3 cards you wouldn't defend — too obvious, too
   wordy, or not how you'd say it. Editing a card to your own words counts double. (If you
   can't find 3 to cut, you're not reading them — the point is the judging rep, not the cut.)
5. File → Import → `m01-cards.txt` → separator: Tab → deck: AI-Mastery.
6. Deck options: enable **FSRS** · desired retention **0.90** · new cards/day **10**.
7. Do today's queue (first day ≈ the 10 new). Done — lane C exists now.

**Self-check:** tomorrow, Anki's queue should offer reviews without you configuring anything.
If it offers 0, the import went to the wrong deck — check the deck list.
