# Project 02 — One full study session, end to end (the machine's shakedown run)

**What:** run the complete ritual once, for real, on module 01's content. ~75 min. This is not
practice for the system — this IS the system, doing its first real lap with you in it.

## Steps

1. Open `interactive/study-cockpit.html` → mode **Study block**. Timers run you; obey them.
2. Session start: open a Claude session, paste the tutor contract
   (`../tutor-contract.md`) — or `/study-session` if you've installed it (ledger 107).
3. Topic: your WEAKEST module-01 area (whatever ex01/ex03 scored lowest — that's the
   weakness-calibrated part). Ask for the 80/20 map of exactly that (move #1).
4. Mid-session: at least one explain-back (move #2) and one close-window-rebuild (move #3).
5. Closing ritual, no skipping: 5-question quiz (no notes) → harsh grades → 3–8 cards drafted
   from the misses → YOU curate → import to the AI-Mastery deck.
6. One `journal.md` daily line + your first weekly block header.
7. Commit everything (journal + any notes). Survival git from module 03's sidebar, or ask the
   tutor session to walk you through the four commands — operating git ≠ the learning work.

## Acceptance checklist

- [ ] Cockpit drove the session (you never checked a clock manually)
- [ ] Contract was active from message one (the tutor refused at least to hand you one answer —
      if it never refused anything, you never pushed it: go back and ask it to "just tell you")
- [ ] Quiz taken, no notes; score recorded in the journal line
- [ ] Cards: drafted ≥3, culled/edited ≥1, imported; FSRS settings confirmed (0.90 / 10 new)
- [ ] Journal line + weekly block header exist and are committed
