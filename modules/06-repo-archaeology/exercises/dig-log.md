# Dig log — append-only; one block per session (the log IS the learning)

Template — copy per session:

```
## dd/mm — <repo> · pass N (<signs|map|doors|slice|jewels|verdict>) · <mins>

CLAIMED (what I expected before looking):
FOUND (what the code actually says — file:line):
CORRECTED (beliefs I had to update):
HOPS (slice sessions only — file:line → one line each):
QUESTIONS for the tutor (concepts only, not summaries):
ONE SENTENCE a stranger would understand:
```

Rules: every FOUND cites file:line · a session with zero CORRECTED entries means you weren't
predicting first — predict, then look · QUESTIONS go to a tutor session at the END of the
dig day, never mid-struggle (30-min rule applies).
